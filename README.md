# LockInPhase

Lock in. Level up. Don't do it alone.

LockInPhase is a productivity app that turns getting stuff done into a game you play with your friends. Knock out your own tasks with a focus timer, rack up XP, and climb levels. Then jump into groups where you set goals together, vote on what matters, and keep each other honest.

## What you can do

* Run focus timers on your tasks and earn XP for finishing them
* Level up and track your streak with a GitHub style heatmap
* Create or join groups with invite codes
* Propose group goals and vote on them democratically
* Chat with your group in real time
* Drop photo proof when you finish something (no faking it)
* Follow the group feed with reactions and comments

## Built with

React Native + Expo, Zustand, Supabase (auth, database, realtime, storage), TypeScript.

## Run it

```bash
npm install
npx expo start
```

Scan the QR with Expo Go and you're in.
